# Rigorous Chebyshev continuation — proof package

Rigorous continuation of solution branches via Chebyshev series in the
parameter: a two-parameter manifold of Cahn–Hilliard steady states, fourteen
arcs of Shigesada–Kawasaki–Teramoto steady states through saddle-node folds, and
the two toy examples of the paper (cube root, square root). This package records
the computer-assisted proofs as statement + inputs + checker; see `statement.md`
for the results, the conditions, and the list of corrections to the original
code and errata of the paper.

The bounds of the two applications are the ones rederived from the paper (not
the original code's). With the paper's norms, the Cahn–Hilliard manifold is
proved for both parameterizations with Chebyshev orders 20 instead of the
paper's 16, and the SKT arcs `u_bar2c`, `u_bar3c` with orders 24, 20 instead of
20, 16: at the paper's orders these cases fail in the paper's norm, so their
inputs were regenerated by the same producer, and the following arcs `u_bar2d`,
`u_bar3d` were regenerated from their new end points so that the arcs still
join. The arc `u_bar3d` needs a larger approximate inverse ($K_A = 250$ instead
of 165). All conditions pass. `statement.md` states exactly which results hold
and lists the errata of the paper.

Check the proofs (Julia 1.13, as pinned in `checker/Manifest.toml`):

```
julia --project=checker checker/verify.jl
```

The full run takes about one hour (2 BLAS threads); almost all of it is the
SKT example. (The last revision was re-checked in parts rather than in one
end-to-end run.) `julia --project=checker checker/verify.jl cahn_hilliard` (or any
subset of `cube_root`, `square_root`, `cahn_hilliard`, `skt`) runs part of it
(exit code 3: not the proof).

Regenerate the inputs (optional, not part of the proof):

```
julia --project=search search/produce.jl [outdir] [examples...]
julia --project=checker tools/hash_data.jl
```

Expansion I*, preprint (2026), [arXiv:2609.22689](https://arxiv.org/abs/2609.22689).
Original code: [OlivierHnt/ChebyshevContinuation.jl](https://github.com/OlivierHnt/ChebyshevContinuation.jl)
(the plotting scripts of its `figures/` folder are not part of this package).
